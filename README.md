# LittleNightmares3-LocalCoopMod

LN3Couch — игра вдвоём на одном ПК в Little Nightmares III

УСТАНОВКА
1. Откройте папку игры и в ней: SMG031MP\Binaries\Win64
   (там лежит файл LittleNightmaresIII.exe).
2. Скопируйте туда СОДЕРЖИМОЕ папки Win64 из этого архива:
   файл dwmapi.dll и папку ue4ss. На вопрос о замене — «Заменить».
3. Запустите игру. Рядом откроется окно UE4SS — так и должно быть.

ИГРА
- Начни одиночную игру.
- В меню паузы (Esc) появится пункт «Кооператив»: там включается второй
  игрок и все настройки. Быстрый вариант — клавиша F9 во время игры.
- Игрок 2 по умолчанию: стрелки — ходьба, Enter — прыжок,
  правый Shift — схватить, правый Ctrl — присесть, / — бег.
- Для второго игрока можно выбрать режим управления: джойстик

УДАЛЕНИЕ
Удалите из SMG031MP\Binaries\Win64 файл dwmapi.dll и папку ue4ss.
