# Little Nightmares III — Local Co-op Mod

**LN3Couch** добавляет локальный кооператив для **Little Nightmares III**, позволяя двум игрокам играть вместе на одном ПК.

> **Важно:** это неофициальная модификация, созданная сообществом. Мод не связан с Bandai Namco Entertainment или Supermassive Games и не поддерживается ими.

## Возможности

* Локальный кооператив для **2 игроков на одном ПК**
* Два игрока находятся в одной игровой сессии
* Второго игрока можно включить через меню паузы
* Быстрое включение Player 2 клавишей **F9**
* Поддержка управления для второго игрока:

    * клавиатура
    * геймпад / контроллер
* Настраиваемое управление Player 2
* Использование **UE4SS**

## Требования

* PC-версия **Little Nightmares III**
* Windows
* Версия игры, совместимая с текущей версией мода
* Для второго игрока рекомендуется отдельный контроллер

## Установка

1. Откройте папку установки Little Nightmares III.

2. Перейдите в:

```text
SMG031MP\Binaries\Win64
```

3. Скачайте последнюю версию мода из этого репозитория.

4. Откройте папку `Win64` из архива мода.

5. Скопируйте её содержимое в папку игры:

```text
SMG031MP\Binaries\Win64
```

После установки структура должна выглядеть примерно так:

```text
SMG031MP\
└── Binaries\
    └── Win64\
        ├── LittleNightmaresIII.exe
        ├── dwmapi.dll
        └── ue4ss\
```

6. Запустите игру.

7. При запуске может появиться окно/консоль UE4SS. Это нормально.

## Как начать игру вдвоём

1. Запустите обычную одиночную игру.
2. Дождитесь загрузки игрового уровня.
3. Откройте меню паузы клавишей `Esc`.
4. Выберите пункт **«Кооператив»**.
5. Включите второго игрока.
6. Настройте управление Player 2.

### Быстрое включение

Второго игрока можно включить непосредственно во время игры клавишей:

```text
F9
```

## Управление второго игрока

Стандартное управление Player 2:

| Действие              | Клавиша     |
| --------------------- | ----------- |
| Движение              | Стрелки     |
| Прыжок                | Enter       |
| Хват / взаимодействие | Right Shift |
| Приседание            | Right Ctrl  |
| Бег                   | `/`         |

Управление может быть изменено в настройках кооператива.

## Управление с контроллера

Player 2 также может использовать геймпад.

Рекомендуемая конфигурация для игры вдвоём:

* **Игрок 1:** клавиатура/мышь или первый контроллер
* **Игрок 2:** отдельный контроллер

Поддержка конкретных моделей контроллеров и их назначений может зависеть от версии мода и игры.

## Как работает мод

LN3Couch работает внутри игры при помощи **UE4SS**.

Игра запускается в обычном одиночном режиме, после чего мод добавляет возможность управления вторым игроком в уже запущенной игровой сессии.

Для этого не требуется запускать вторую копию игры.

Это именно **локальная модификация для совместной игры**, а не реализация официального сетевого мультиплеера.

## Важно

Модификация изменяет поведение игры во время её работы.

Поскольку Little Nightmares III изначально не предназначена для такого варианта локальной игры, некоторые игровые механики могут работать иначе или иметь ограничения.

Мод находится в разработке.

При обнаружении ошибки желательно указать:

* версию игры;
* версию мода;
* описание проблемы;
* последовательность действий, приводящую к ошибке;
* способ управления Player 2 — клавиатура или контроллер;
* скриншот или видео;
* лог UE4SS, если он относится к проблеме.

## Устранение проблем

### Игра не запускается

Проверьте:

1. `dwmapi.dll` находится непосредственно в:

```text
SMG031MP\Binaries\Win64
```

2. Папка `ue4ss` также находится непосредственно в `Win64`.
3. Файлы мода не были помещены во вложенную папку `Win64`.

Правильно:

```text
Win64\
├── dwmapi.dll
└── ue4ss\
```

Неправильно:

```text
Win64\
└── Win64\
    ├── dwmapi.dll
    └── ue4ss\
```

### Пункт «Кооператив» не появляется

Проверьте:

* правильно ли загружается UE4SS;
* находятся ли файлы мода в правильной папке;
* запущена ли непосредственно игровая сессия, а не главное меню;
* соответствует ли версия игры версии мода.

Также попробуйте нажать:

```text
F9
```

непосредственно во время игры.

### Второй игрок не реагирует на управление

Проверьте настройки Player 2 и убедитесь, что выбранная клавиатура или контроллер корректно распознаётся системой.

Если используется контроллер, попробуйте временно отключить другие контроллеры и проверить работу ещё раз.

## Удаление мода

Чтобы удалить LN3Couch, удалите:

```text
SMG031MP\Binaries\Win64\dwmapi.dll
```

и папку:

```text
SMG031MP\Binaries\Win64\ue4ss
```

Оригинальные файлы игры при этом изменяться не должны.

## Известные ограничения

Мод находится в разработке.

Некоторые игровые механики могут вести себя иначе при двух локальных игроках, поскольку оригинальная игра использует собственную систему игроков и сетевого кооператива.

Если вы обнаружили воспроизводимое ограничение, сообщите о нём через GitHub Issues, чтобы оно могло быть добавлено в этот раздел.

## Часто задаваемые вопросы

### Это официальный мод?

Нет. LN3Couch — неофициальная модификация, созданная сообществом.

### Это split-screen?

Мод добавляет возможность играть вдвоём локально на одном ПК. Поведение камеры и отображения зависит от текущей реализации мода.

### Нужны две копии игры?

Нет. Мод работает внутри одной запущенной копии игры.

### Можно ли использовать два контроллера?

Player 2 поддерживает контроллер. Конкретная конфигурация зависит от текущей версии мода.

### Можно ли играть вдвоём на одной клавиатуре?

Да. Для Player 2 предусмотрено отдельное управление клавиатурой.

Однако для комфортной игры рекомендуется использовать отдельный контроллер для второго игрока.

### Мод заменяет официальный онлайн-кооператив?

Нет. Мод добавляет локальный вариант игры и не заменяет официальную сетевую игру.

### Будет ли мод работать после обновления игры?

Не обязательно.

Обновления игры могут изменить внутренние структуры или функции, от которых зависит работа UE4SS-мода.

После обновления Little Nightmares III проверьте наличие новой версии LN3Couch.
