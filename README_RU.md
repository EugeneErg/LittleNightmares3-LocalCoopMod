# LN3Couch — локальный кооператив для Little Nightmares III

<p align="center">

**Играйте в Little Nightmares III вдвоём на одном ПК.**

Клавиатура + контроллер • Динамический split-screen • Одна игровая сессия

</p>

> **LN3Couch** — неофициальный мод, добавляющий локальный кооператив для двух игроков в **Little Nightmares III**.

---

## Возможности

* **2 игрока на одном ПК**
* Не требуется вторая копия игры
* Второй игрок может использовать **клавиатуру или контроллер**
* Игроки могут использовать разные устройства ввода
* **Динамический split-screen**
* Автоматическое переключение между общей камерой и разделённым экраном
* Несколько режимов split-screen
* Настройки кооператива прямо в игре
* Переназначение клавиш второго игрока
* Сохранение настроек между запусками
* Включение и выключение кооператива во время игры
* Кнопка **«Кооператив»** непосредственно в меню паузы
* Работает через **UE4SS**

---

# Как работает мод

Little Nightmares III уже содержит системы, необходимые для управления вторым персонажем.

LN3Couch использует существующую архитектуру игры вместо создания полностью отдельной multiplayer-системы.

При включении локального кооператива схема выглядит примерно так:

```text
Игрок 1
   │
PlayerController
   │
Персонаж 1


Игрок 2
   │
AI Controller
   │
Персонаж 2
```

AI второго персонажа временно отключается, после чего LN3Couch передаёт ему команды локального игрока.

Благодаря этому используются существующие:

* персонаж;
* анимации;
* движение;
* взаимодействия;
* игровые механики.

Дополнительно создаётся второй Unreal `PlayerController`, необходимый для второго viewport и камеры.

---

# Динамический split-screen

LN3Couch не заставляет игру постоянно находиться в режиме разделённого экрана.

Мод может автоматически определять, находятся ли оба персонажа в пределах одной камеры.

### Автоматический режим

Если игроки находятся рядом:

```text
┌──────────────────────────────┐
│                              │
│       P1          P2         │
│                              │
│        Общая камера          │
│                              │
└──────────────────────────────┘
```

Если игроки расходятся:

```text
┌───────────────┬───────────────┐
│               │               │
│      P1       │       P2      │
│               │               │
│    Камера 1   │    Камера 2   │
│               │               │
└───────────────┴───────────────┘
```

Когда игроки снова сближаются, мод может вернуть общую камеру.

Для предотвращения постоянного переключения используются разные пороги включения и выключения split-screen.

---

# Режимы split-screen

| Режим      | Описание                                                       |
| ---------- | -------------------------------------------------------------- |
| `Auto`     | Автоматическое переключение между общей камерой и split-screen |
| `Distance` | Переключение на основе расстояния между игроками               |
| `Always`   | Всегда использовать split-screen                               |
| `Never`    | Никогда не использовать split-screen                           |

Автоматический режим в первую очередь использует положение второго игрока относительно экрана и при необходимости может перейти на проверку расстояния.

# Управление второго игрока

## Клавиатура

Стандартное управление:

| Действие              | Клавиша     |
| --------------------- | ----------- |
| Движение              | Стрелки     |
| Прыжок                | Enter       |
| Хват / взаимодействие | Right Shift |
| Приседание            | Right Ctrl  |
| Бег                   | `/`         |

Клавиши можно изменить в меню LN3Couch.

## Контроллер

Второй игрок может использовать отдельный геймпад.

Поддерживаются:

* левый стик;
* правый стик;
* A;
* B;
* LT;
* RT.

Для стиков предусмотрена настройка deadzone.

# Установка

## Требования

* **Little Nightmares III — PC-версия**
* Windows
* Совместимая версия игры
* Файлы UE4SS, входящие в состав мода

## Установка

1. Скачайте последнюю версию из раздела **Releases**.

2. Откройте папку с игрой.

3. Перейдите:

```text
SMG031MP\Binaries\Win64
```

4. Скопируйте содержимое папки `Win64` из архива мода в папку `Win64` игры.

В результате структура должна выглядеть примерно так:

```text
SMG031MP\
└── Binaries\
    └── Win64\
        ├── LittleNightmaresIII.exe
        ├── dwmapi.dll
        └── ue4ss\
```

5. Запустите Little Nightmares III.

6. Начните или загрузите игру.

7. Откройте меню паузы и выберите **«Кооператив»**.

Также можно открыть меню LN3Couch клавишей:

```text
F9
```

---

# Быстрый запуск

1. Запустите игру.
2. Начните игру.
3. Нажмите **F9**.
4. Включите второго игрока.
5. Подключите/настройте контроллер или клавиатуру второго игрока.
6. Играйте.

---

# Меню кооператива

LN3Couch добавляет собственное меню настроек.

В нём доступны:

* включение/выключение второго игрока;
* настройка управления Player 2;
* режим split-screen;
* дистанция переключения;
* назначение клавиш;
* настройки контроллера;
* сброс настроек.

Кроме того, кнопка **«Кооператив»** добавляется непосредственно в стандартное меню паузы игры.

---

# Настройки

Настройки сохраняются в:

```text
ue4ss\Mods\LN3Couch\settings.lua
```

Поэтому выбранная конфигурация сохраняется между запусками игры.

# Техническая информация

LN3Couch реализован как Lua-мод для **UE4SS**.

Мод максимально использует существующие системы Little Nightmares III, вместо того чтобы полностью заменять архитектуру игроков.

## Второй игрок

Мод находит существующий `KosmosAIController` и связанный с ним персонаж второго игрока.

В частности, используются классы:

```text
BP_Low_C
BP_Alone_C
```

После включения кооператива AI второго персонажа временно останавливается, а управление передаётся LN3Couch.

Упрощённо:

```text
Существующий второй персонаж
          │
          ▼
   KosmosAIController
          │
       AI отключён
          │
          ▼
    Ввод LN3Couch
          │
          ▼
      Игрок 2
```

Так мод может использовать существующие системы движения и взаимодействия игры.

---

# Камера второго игрока

Для второго игрока используется отдельный `CameraActor`.

Камера следует за вторым персонажем, сохраняя положение относительно основной камеры.

Это позволяет создать отдельный вид для второго игрока без полной замены существующей системы камер Little Nightmares III.

В зависимости от режима мод может включать или отключать второй viewport.

---

# Второй PlayerController

При включении локального кооператива LN3Couch создаёт дополнительный Unreal `PlayerController`, необходимый для второго локального viewport.

При этом второй PlayerController не является основным владельцем Pawn второго игрока.

Схема:

```text
PlayerController 1
        │
        └── Игрок 1

AI Controller
        │
        └── Игрок 2

PlayerController 2
        │
        └── Второй viewport / камера
```

Так сохраняется существующая игровая логика второго персонажа.

# Известные ограничения

LN3Couch находится в разработке.

Поскольку Little Nightmares III изначально не предназначена именно для такой локальной конфигурации, некоторые ситуации могут работать иначе, чем в официальном режиме игры.

Особенно чувствительными к обновлениям игры могут быть:

* создание PlayerController;
* система камер;
* интерфейс меню паузы;
* классы персонажей и AI;
* обработка ввода;
* переходы между уровнями;
* возрождение;
* чекпоинты.

Если проблема воспроизводится, пожалуйста, создайте Issue.

# Решение проблем

## Игра не запускается

Проверьте, что:

```text
dwmapi.dll
```

находится непосредственно в:

```text
SMG031MP\Binaries\Win64
```

и папка:

```text
ue4ss
```

также находится непосредственно в `Win64`.

### Правильно

```text
Win64\
├── dwmapi.dll
└── ue4ss\
```

### Неправильно

```text
Win64\
└── Win64\
    ├── dwmapi.dll
    └── ue4ss\
```

---

## Кооператив не появляется

Проверьте:

1. Запущена ли игровая сессия.
2. Нажмите `F9`.
3. Загружается ли UE4SS.
4. Находятся ли файлы в правильной папке.
5. Совместимы ли версии игры и мода.

---

## Второй игрок не реагирует

Проверьте:

* назначение клавиш;
* подключение контроллера;
* выбранное устройство управления;
* не мешает ли другой подключённый контроллер.

При проблемах с контроллером попробуйте временно отключить остальные контроллеры.
